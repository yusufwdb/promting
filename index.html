Module 01

Introduction to Prompt Engineering

Big Idea: A language model produces a continuation of the information it receives. Prompt engineering is the practice of making that continuation useful, relevant, and reliable.

1. How Did We Get Here?

From statistical Markov chains to seq2seq with attention, and the 2017 Transformer architecture (Attention Is All You Need), prompt engineering emerged because large pre-trained generative models (GPT) adapt dynamically to context.

EraDevelopmentSignificance
1940s+Statistical N-gramsPredicts words from 1–3 preceding words.
2014Seq2seq modelsEncoder compresses input into a single fixed "thought vector".
2015Neural AttentionEliminates single vector bottleneck; queries all input tokens.
2017The TransformerAttention becomes the entire architecture.
2018+GPT-1 to GPT-4Pre-trained autoregressive models conditioned via prompts.

2. What GPT Stands For

Generative

Generates text autoregressively: \(P(t_{n+1} \mid t_1, \ldots, t_n)\).

Pre-trained

Learns language and world representations from vast internet corpora.

Transformer

Uses multi-head attention mechanisms to link context positions.

Module 02

Understanding How Language Models Work

Big Idea: Understand what the model processes: tokens, probability distributions, and context.

1. The Generation Loop & Softmax Formula

Text is converted into token IDs. Scores (logits \(z_i\)) are transformed into probabilities via Softmax at temperature \(T\):

$$p_i(T) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$
⚡ Live Temperature Simulator ("The cat sat on the…") T = 0.7

2. Five Defenses Against Hallucinations

1. Grounding Excerpts

Provide verified source documents in the prompt.

2. Explicit Fallback

Instruct the model to say "I don't know" when missing.

3. External Tools

Use search and APIs for live or private data.

4. External Validation

Run code tests, linters, and schema checkers.

Module 05

Prompt Content, Context, and RAG

Big Idea: The quality of response depends on which information enters the prompt.

Lexical vs Neural Retrieval

Lexical (Jaccard / BM25)

$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

Best for exact IDs, error codes, and verbatim matches.

Neural (Cosine Embeddings)

$$\operatorname{cosim}(\mathbf{a}, \mathbf{b}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|}$$

Best for semantic meaning, synonyms, and multilingual search.

Sliding Window Snippetizing

def snippetize(text, window_words=200, stride_words=120):
    words = text.split()
    return [" ".join(words[i:i+window_words]) for i in range(0, len(words), stride_words)]
Module 06

Prompt Engineering Laboratory Workbook

Your Mission: Treat prompts as reproducible experimental designs.

Lab 1: Reasoning & Fallacies (24 Controlled Runs)

Testing 8 Argument Cases across 3 Strategies (Zero-Shot, Few-Shot, Few-Shot + Structured):

Case A

“Sales started falling after we introduced a new logo. This proves that the logo change discouraged customers.”

False Cause (Post hoc): Temporal order alone does not prove causation.
Case B

“This supplement must work because a famous actor said in an interview that it made them feel great.”

Appeal to Authority: Celebrity testimonial is not medical proof.
Case C

“I met two rude waiters at this restaurant chain. Clearly, the entire company has terrible staff.”

Hasty Generalization: Sample size of 2 cannot generalize across an entire company.
Case D

“If we allow students to use phones in class, within a year nobody will pay attention and education will collapse.”

Slippery Slope: Catastrophic chain asserted without justifying each link.
Case H

“A study involving 10,000 people indicates that exercise reduces heart disease. Therefore, programs encouraging exercise are worthwhile.”

No Clear Fallacy: Substantial empirical sample supporting a proportionate recommendation.
